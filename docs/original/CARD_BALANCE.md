# 卡牌统一价值表

本表是卡牌数值、掉落等级与自动战斗估值的统一参考。实际效果必须以 `src/game.mjs` 的结构化字段和 `card()` 计算结果为准，卡面描述与结算不得另写第二套公式。

## 1. 成长公式

- 每张卡牌配置中的伤害、护盾、治疗、弱点与延迟护盾，就是玩家看到的 Lv.1 最终数值；不再进行隐藏的章节修正。
- 章节差距由各章卡牌的初始配置和效果机制直接体现。
- 普通卡牌等级倍率：`1 + (Lv - 1) × 0.34`，作用于伤害、护盾、治疗、弱点与延迟护盾，最终四舍五入。
- 同一张牌直接享受伤害、护盾、治疗中两类装备属性的双属性卡，先按普通倍率成长，再从伤害、护盾、治疗的总牌面中扣除 `round((Lv - 1) × 1.5)`，按原效果比例分摊。弱点、抽牌、能量和已有护盾转伤不算第二类装备属性。
- “开场白”的弱点例外，任何等级都固定为 `1` 层，只有伤害随等级成长。
- 大叔每回合第一次使用发现弱点的牌后抽 `1` 张牌，不额外增加弱点层数；装备不参与弱点计算。
- 抽牌在 Lv.6 增加 1，能量在 Lv.8 增加 1；生命代价每 4 级减少 1，最低 1。

## 2. 掉落等级

```text
普通怪：1 + 2 ×（当前章节 - 卡牌所属章节）
精英怪：普通怪等级 +1
Boss：普通怪等级 +2
等级最终限制在 Lv.1 至 Lv.10
```

章内步数不再改变卡牌等级。新卡无论是否已拥有同名卡，都作为独立卡牌进入候补。

## 3. 效果估值

第一版自动战斗使用以下相对价值，数值用于选牌而不是显示给玩家：

| 效果 | 基础估值 |
| --- | ---: |
| 实际预计伤害 | 1.00 / 点 |
| 对应本回合来袭的护盾 | 1.15 / 点 |
| 实际缺血范围内的治疗 | 1.10 / 点 |
| 弱点 | 普通角色 2.7 / 层；大叔 4.0 / 层（延时输出选牌估值） |
| 抽牌 | 5 / 张 |
| 能量 | 6 / 点 |
| 从弃牌堆回收 | 4 / 张 |
| 延迟护盾 | 0.55 / 点 |
| 解除有效负面状态 | 12 |

费用为 0 的牌按 `0.65` 费折算，其他牌按实际费用折算。可能令玩家在来袭伤害下死亡的自伤牌会受到极大扣分。

弱点是延时输出：每个攻击段消耗 `1` 层弱点，固定追加 `4` 点无视护盾伤害。攻击不再按当前弱点总层数追加伤害，多张标记牌因此只线性增加可触发次数。表中每层 `2.7/4.0` 是考虑战斗结束前可能无法全部兑现后的选牌估值，不是实际单次触发伤害。

### 3.1 章节收益曲线

当前章 Lv.1 卡以“每 1 费等价收益”作为统一数值基准。第一章 1 费卡的起始等价收益为 `10`，伤害、护盾、治疗、弱点、抽牌、能量、回收和延迟效果必须按上表权重折算，不能直接相加卡面数字。多费卡先计算完整效果价值再除以费用；0 费卡继续按 `0.65` 费折算。

同时直接享受两类装备属性成长的双属性卡，Lv.1 裸卡原则上只使用同章同费目标预算的约 `85%–90%`；升级后在普通成长结果上每级额外扣除约 `1.5` 点总牌面，剩余空间由同期第二条装备属性补足。基准案例：第一章 Lv.3 单属性牌约为 `17` 点，Lv.3「我在这里」和「热可可」的裸卡总收益均为 `12` 点，正好为预期约 `5` 点的第二条装备属性留出空间。采用固定扣除而非低比例成长，避免第五、六章的高基础值双属性卡受到成倍惩罚；差额仍会随等级扩大，使双属性卡的后期收益主要来自装备成型。固定机制效果（如弱点、抽牌、能量、回收和已有护盾转伤）不自动视为第二类装备属性成长，仍按实际机制价值单独估算。

当前按此规则处理的九张牌是：我在这里、热可可、晚安花茶、共撑一伞、再坐一会儿、好好睡一觉、温茶在手、守到天明、最后热饮。

| 章节 | 相对第一章倍率 | 每 1 费目标等价收益 | 机制要求 |
| ---: | ---: | ---: | --- |
| 第一章 | `1.0` | 约 `10` | 建立基础攻击、防御、治疗、抽牌与弱点结构 |
| 第二章 | 约 `1.5` | 约 `15` | 扩展多段、保留与组合出牌 |
| 第三章 | 约 `1.7–2.0` | 约 `17–20` | 扩展抽牌、回收与延迟生效 |
| 第四章 | 约 `2.0–2.5` | 约 `20–25` | 加入资源转换 |
| 第五章 | 约 `3.0–6.0` | 约 `30–60` | 加入终结机制与高压续航 |
| 第六章 | 约 `6.0–10.0` | 约 `60–100` | 形成终局组合 |

该曲线衡量战斗内的单次使用强度，不与金币影子价格同比增长。后期卡剩余可使用场次更少，因此第六章卡可以达到第一章卡 `6–10` 倍战斗收益，而经济影子价格仍只从 `45–60` 旅币增长到 `140–180` 旅币。旧章节卡在后续章节以更高等级掉落，评估新卡时必须同时比较同场景下旧卡的实际掉落等级，避免新章 Lv.1 卡被高等级旧卡严格替代。

## 5. 特殊机制

- `recycle`：从弃牌堆末端取回指定数量卡牌，受 9 张手牌上限限制。
- `nextBlock`：记录到下一回合开始，再与装备、遗物和角色保留护盾共同结算。
- `blockDamage`：按打牌时的当前护盾比例追加伤害。
- `execute`：敌人生命不高于 50% 时放大该卡基础攻击伤害。
- `markBurst`：按使用该牌前已有的弱点层数乘以卡牌系数，立即造成无视护盾伤害，不消耗弱点。
- `retain`：未打出的牌在回合结束时仍留在手牌中；打出后仍会正常进入弃牌堆。
- `exhaust`：打出后移出本场战斗，不会随弃牌堆重新洗回抽牌堆；下一场战斗会正常恢复。
- `consumeMark`：消耗全部弱点，并按每层指定数值造成无视护盾伤害。
- `cleanse`：解除治疗压制与动摇。

## 7. 敌人章节机制

跨章时地图深度会从第 `50` 步归零，因此敌人强度额外设置跨章下限。第二章普通怪的生命/峰值攻势下限为前章末段最强普通怪的 `120%/120%`，精英相对前章 Boss 为 `110%/108%`；第三至第六章普通怪依次为 `145%/125%`、`135%/128%`、`135%/132%`、`140%/136%`，精英依次为 `135%/112%`、`135%/116%`、`140%/120%`、`145%/124%`。实际结算取跨章下限与当前章节、深度、难度公式中的较高值，承接新版专精在 15/30/50 点投入门槛后的成长，避免玩家击败 Boss 并获得专精后，下一章反而明显变简单。

Boss 生命身份倍率从第一至第六章依次为 `1.65/1.9/2.35/2.8/5.3/7.7`。第三至第六章的每回合进攻成长在当前难度基础值上额外增加 `0.02/0.04/0.06/0.07`；该加成不影响首回合，只用于压制依靠高额治疗或护盾无限拖延的打法。

- 第二章起：周期性蓄力，本回合预告，下回合释放。
- 第三章起：周期性驱散一半护盾后攻击。
- 第四章起：周期性施加两回合 50% 治疗压制。
- 第五章起：周期性向弃牌堆塞入“杂念”。
- 第六章会同时使用以上机制，要求玩家根据可见意图调整出牌。
- 终章 Boss 不使用会长期覆盖其原始攻击的通用四回合替换序列：奇数回合保留原始攻击或诅咒，偶数回合在驱散、蓄力和治疗压制间切换，使反击有可预期的触发频率，同时继续限制纯护盾与纯治疗拖延。
- 小帅的反击与潮汐终极专精会降低 `8%` 护盾穿透，挑战难度仍保留 `17%` 穿透；「越打越牢」每级在成功格挡后提供 `3` 点下回合护盾和 `2` 点治疗，避免后期固定穿盾令整条路线失效。

## 8. 装备掉落

装备底材依物品等级使用普通 `1.0`、进阶 `2.2`、精英 `4.0` 的档位倍率，每档内部每级增加 `2%`；传奇品质的底材基础伤害、护盾、恢复与首次攻击最终再乘 `1.35`。品质倍率不放大随机词条。

| 敌人 | 0 件 | 1 件 | 2 件 | 3 件 |
| --- | ---: | ---: | ---: | ---: |
| 普通怪 | 40% | 45% | 12% | 3% |
| 精英怪 | 0% | 32% | 56% | 12% |
| Boss | 0% | 0% | 40% | 60% |

同一场战斗最多一件装备附带技能。装备技能为 0 费临时牌，不进入技能库、不占出战数量，也不能参与合成。

### 8.1 品质概率

| 遭遇 | 第一章 普通/精良/稀有/传奇 | 第六章 普通/精良/稀有/传奇 |
| --- | --- | --- |
| 普通怪 | 52% / 36% / 12% / 0% | 44.5% / 36% / 18% / 1.5% |
| 精英怪 | 42% / 36% / 18% / 4% | 34.5% / 36% / 18% / 11.5% |
| Boss | 36% / 36% / 18% / 10% | 28.5% / 36% / 18% / 17.5% |

中间章节每章把普通品质向传奇品质平移 1.5 个百分点。精英与 Boss 使用独立加成，不能共用同一个“强化掉落”开关。

### 8.2 装备技能概率

- 无自带技能的底材：普通、精良品质不会附带随机技能；稀有为 20%，传奇为 60%。普通怪还会乘章节倍率 `15% / 30% / 45% / 60% / 80% / 100%`，精英与 Boss 不乘衰减。
- 有自带技能的底材：普通怪沿用章节倍率；精英额外增加 15 个百分点，Boss 额外增加 25 个百分点，最高 100%。第一章分别为 15%、30%、40%。
- 无论一次掉落多少件装备，同一场战斗最多保留一件带技能的装备。
