# 下一站，晚安

一款移动端优先的房车旅店卡牌 RPG。房车既是玩家整理装备和选择目的地的基地，也会在故事中前往不同地区。玩家在黄昏停靠，入夜后进入当地客人的梦境，通过可重复探索的随机路线获得卡牌、经验和装备。

## 开发

```bash
npm install
npm run dev
```

默认开发地址由 Vite 输出。当前会话使用 `http://127.0.0.1:4178/`。

像素素材源图位于 `src/assets/pixel/`。修改源图后运行：

```bash
npm run assets
```

命令会切分章节背景和敌人图集、清理透明背景，并将压缩后的 WebP 写入 `src/assets/pixel/runtime/`。

## 验证

```bash
npm test
npm run build
```

生产文件生成到 `dist/`。项目没有网络接口、账号系统或付费功能，游戏进度保存在浏览器本地存储中。

## 游戏流程

1. 房车基地：选择战斗模式和目的地，整理装备、背包与梦境卡。
2. 地图：每次出发都会生成新的不规则路线；探索包含 50 步，每一步最多出现 3 个候选节点。每 10 步停靠夜程路标，可恢复、强化卡牌或补充旅币。
   战败后会从最近路标继续；尚未抵达首个路标时则返回房车，长期成长不会清空。
3. 战斗：可以在房车中切换自动出牌或手动出牌，并选择舒缓、标准或挑战难度。默认标准难度比原始版本更强，较高难度同时提高奖励。
   所有行动进入实时日志；伤害与治疗显示浮动数值，致命一击会完整播放后再进入胜负结算。
4. 敌人生态：每个区域包含浅层梦影、深层异象、精英与最终首领，随夜程切换行动模式。章节场景与敌人像素立绘分层显示，敌人拥有待机、受击和退场反馈。
5. 奖励：击败敌人后从三张牌中选择一张，也可以跳过。
6. 节点：普通战斗、强化精英、随机事件和营地会改变本轮资源。
7. 刷宝：击败区域首领后返回房车并解锁下一站，已通关区域可反复进入。
8. 随机装备：同一底材可重复掉落，品质决定随机词条数量，高品质装备可能附带技能卡。
9. 房车工坊：比较装备评分，重铸随机词条或整理闲置装备换取旅币。
   旅币也可升级暖灯厨房、随车工坊和旅客房间，提供永久恢复、折扣与心力成长。
10. 客人故事：六位旅客各有三段故事，反复探索可推进关系并领取专属传奇纪念品。
    旅程委托持续记录战斗、节点和章节进度，完成后刷新更高一档目标并奖励旅币。
11. 技能构筑：倾听、陪伴、料理、书信、回忆和清醒梦六类技能支持不同出牌节奏。
12. 成长：战斗提供经验和装备，等级、卡组及装备永久保留。
